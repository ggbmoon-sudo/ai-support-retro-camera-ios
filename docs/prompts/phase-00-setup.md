Create the initial repo structure, documentation layout, AGENTS.md, placeholder folders, Firebase placeholder files, Cloud Functions placeholder files, scripts, and phase log.

## Do

- Create README.md

- Create docs/

## Do Not

## Acceptance Criteria

- Repo structure exists.
- Documentation exists.
- No secrets are committed.
- Phase log is updated.
- Ready for Phase 01.
